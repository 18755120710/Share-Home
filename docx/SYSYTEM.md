# 产品需求文档 (PRD) - Share Home

**版本：** V1.0  
**定位：** 轻量级、极速、无需公网的局域网资源共享与协作平台。

---

## 1. 产品愿景与价值
*   **愿景：** 让局域网内的设备连接像呼吸一样自然。
*   **核心价值：**
    *   **极速：** 利用物理带宽极限，文件传输不限速。
    *   **私密：** 数据不经过公网，确保隐私安全。
    *   **零配置：** 无需复杂的 IP 输入，自动发现同网络下的伙伴。

---

## 2. 核心功能模块 (MVP 版本)

### 2.1 自动发现与连接 (Discovery)
*   **功能描述：** 只要电脑接入同一个 WiFi 或网线，打开平台即可看到彼此。
*   **需求点：**
    *   基于 mDNS/UDP 广播协议实现自动发现。
    *   用户可自定义昵称和头像。
    *   在线状态实时更新。

### 2.2 极速文件传输 (File Transfer)
*   **功能描述：** 支持超大文件、文件夹的拖拽式互传。
*   **需求点：**
    *   **断点续传：** 网络波动导致中断后，可从上次进度继续。
    *   **多任务处理：** 支持同时发送/接收多个文件。
    *   **直观进度条：** 显示实时速度、剩余时间。

### 2.3 局域网“公告栏” (The Board) - **你的创意延伸**
*   **功能描述：** 一个公共的信息流，所有人可以在上面发帖。
*   **需求点：**
    *   **代码片段（Gist）：** 支持主流语言语法高亮（C++, Python, JS等），一键复制。
    *   **剪贴板同步：** A 电脑复制一段文字，B 电脑在公告栏看到并直接使用。
    *   **富文本/Markdown：** 支持发布简单的技术笔记或通知。

### 2.4 文件浏览与提取 (Shared Storage)
*   **功能描述：** 用户可以设置一个“公共共享文件夹”，允许他人浏览并下载。
*   **需求点：**
    *   **权限控制：** 可设置“仅查看”或“可上传”。
    *   **网页化访问：** 对方不一定要安装客户端，通过浏览器输入生成的本地 IP 链接即可下载。

## 3. 进阶功能规划 (PM 的脑洞延伸)

为了让这个平台更有竞争力，我建议加入以下功能：

1.  **屏幕共享/远程镜像：** 无需安装向日葵，一键将自己的屏幕演示给局域网内的同事看。
2.  **“阅后即焚”模式：** 传输敏感密码或私密文档，对方接收并关闭后，文件自动在对方本地物理删除（或仅存在于内存中）。
3.  **多端联动：** 除了两台电脑，增加手机端（安卓/iOS）。手机拍的照片，一键“甩”到电脑上。
4.  **本地 Webhook 机器人：** 如果你是开发者，可以写个脚本，当某个程序运行完后，自动往 NexusLAN 的公告栏发一条消息提醒大家。

## 4. 业务流程/用户路径

1.  **发现：** 用户 A 打开软件 -> 看到列表里的“用户 B”。
2.  **交互：**
    *   **传文件：** A 将文件拖到 B 的头像上 -> B 弹出提醒“是否接收” -> 点击确定 -> 开始 P2P 传输。
    *   **发代码：** A 在公告栏点击“新建代码” -> 输入 Python 脚本 -> 点击发布 -> 局域网内所有在线用户收到通知并可查看。
3.  **查看：** 用户 B 可以在“共享空间”里看到 A 允许公开的所有文件。

---

## 5. 技术架构建议 (给开发者的参考)

*   **前端框架：** Nest.js(全栈开发)
*   **后端/核心：** Rust(辅助)
*   **通讯协议：**
    *   **发现协议：** mDNS (类似 AirDrop 的原理)。
    *   **数据传输：** TCP/HTTP2 (稳定) 或 WebRTC (点对点穿透)。
*   **数据库（本地）：** SQLite 或 LevelDB (记录历史传输和代码片段)。

---

## 6. 非功能性需求

*   **易用性：** 无需注册账号，打开即用。
*   **性能：** 在千兆网环境下，传输速度应达到 80-100MB/s。
*   **资源占用：** 后台静默运行内存占用应小于 100MB。
